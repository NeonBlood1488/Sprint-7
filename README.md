# Sprint_7 — API-тесты для сервиса «Самокат»
Проект содержит автотесты для API сайта Яндекс Самокат, ссылка на к-рый https://qa-scooter.praktikum-services.ru/

## Проверяемые ручки
- **Создание курьера** (`POST /api/v1/courier`);
- **Логин курьера** (`POST /api/v1/courier/login`);
- **Создание заказа** (`POST /api/v1/orders`) — с параметризацией цветов;
- **Получение списка заказов** (`GET /api/v1/orders`);
